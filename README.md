# Treinamento de pull requests

Repositório de exercícios para praticar organização de código e fluxo de colaboração com Git e GitHub.

## Arquivos

- login.py — exemplo simples de entrada de usuário e senha pelo terminal.
- tela_home.py — exemplo de mensagens exibidas em uma tela inicial.

Os arquivos são demonstrações independentes e não implementam autenticação real nem uma aplicação completa.
